## SnapInk 功能全景（README 梳理，2026-08-13）
- **截**：区域/全屏（鼠标所在显示器）/延时（1-60s+倒计时音）/长截图（滚动）。
- **标**：9 种标注（矩形/椭圆/直线/箭头/画笔/文本/序号徽章/马赛克/聚光灯），对象可编辑（移动/缩放/改样式/撤销/重做），样式持久化，文字+Logo 水印（{date}/{time}/{datetime} 占位）。
- **读**：本地 OCR（中英，Vision）+ 英译中（Apple Translation，macOS 15+，离线）。
- **贴**：贴图置顶窗口、贴图库（SHA-256 去重、100 张）、透明/圆角/全桌面/像素移动。
- **录**：MP4（30fps H.264/AAC）+ 自适应 GIF（720px/15fps）、系统音频+麦克风混音、光标、暂停/继续、实时标注进视频、水印烧录。
- **平台**：菜单栏常驻、全局快捷键可配置（去重）、Universal 2、macOS 13+、纯原生零依赖、全本地处理。
- 叙事：**截 → 标 → 读 → 贴**。计划：活动窗口截图、Developer ID 签名公证。

## CatchInk 查证 + 命名方法学发现（2026-08-13 11:23）
- 用户提出 **CatchInk**（动词前置 X+Ink 结构）。查证：双端 App Store 无直接同名 ✓；无已知品牌（仅相关：Catch简影-优友视界2015短视频，已沉寂；Catch记事本-Catch Notes 笔记 app，Catch 单词在 app 圈用量大）。
- **硬伤：发音 -ing 歧义**。CatchInk 连读 ≈ /kætʃɪŋk/，极接近 "catching"，口头传播会被听成/写成 Catching，拼写无法从听觉还原。
- **系统性规律：X+Ink（动词前置）几乎必有 -ing 歧义**（CatchInk≈catching、ReelInk≈reeling、FrameInk≈framing、LoopInk≈looping、TapeInk≈taping）；**Ink+X（墨前置）发音全部干净**（InkCatch/InkReel/InkFrame/InkLoop/InkTape）。→ 命名姿势应是 Ink+X，不是 X+Ink。
- 若用户坚持 Catch 动作词：**InkCatch**（双端已查干净）发音无歧义，但覆盖仅截+标+水印 3/7，仍不如 InkReel 5.5/7 / InkFrame。
