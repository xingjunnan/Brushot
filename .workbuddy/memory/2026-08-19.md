## Brushot README 多语言化与开源化（GitHub README 改造）

Capso、openClaw 这类 macOS screenshot 项目的 GitHub 仓库常见的：
- 顶部 `English | 简体中文 | 日本語 | 한국어` 语言切换
- README / Contributing / License 三个 Tab
全是 **GitHub 原生机制**，零依赖、零成本，并非第三方插件或 Action。

### GitHub 原生机制要点
- 在仓库根目录放置 README 的 BCP 47 后缀副本即可被 GitHub 自动识别：
  - `README.md` → English（默认）
  - `README.zh-CN.md` → 简体中文（**最稳的命名，Capso 用这个**）
  - `README.zh-TW.md` → 繁體中文
  - `README.ja.md` → 日本語
  - `README.ko.md` → 한국어
- **LICENSE** / **CONTRIBUTING.md** 文件名命中即出现对应 Tab。
- 中文习惯用 `zh-CN` / `zh-TW`，**不用** `zh-Hans` / `zh-Hant`（后者主要给 App 内部 Localization 用）。
- GitHub 还认 `zh-Hant` / `zh-Hans` 做 locale 文件，但对仓库 README 用 `zh-CN` / `zh-TW` 最稳。
