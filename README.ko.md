# Brushot

Brushot은 가볍고 네이티브한 macOS용 스크린샷 앱으로, 빠른 캡처, 주석, OCR, 핀 고정, 화면 녹화를 지원합니다. 현재 빌드는 캡처와 인라인 주석의 완전한 루프를 포함합니다:

macOS 13 이상에서 Apple Silicon과 Intel Mac 양쪽을 Universal 2 바이너리로 지원합니다.

- 메뉴바 앱
- 영역 / 전체 화면 / 지연 / 스크롤 캡처, 녹화, 클립보드에서 핀 고정, 핀 라이브러리, 핀 모두 숨기기/보이기 등 글로벌 단축키를 환경설정에서 모두 사용자 지정
- 드래그로 영역을 선택하는 캡처 오버레이
- 포인터 아래의 가장 앞쪽 창을 자동 감지: 클릭하면 창 전체를 선택하고 드래그하면 자유 영역을 선택
- 싱글 디스플레이 전체 화면 캡처, 마우스가 있는 디스플레이를 자동으로 타깃
- 1–60초 지연 영역 캡처, 카운트다운 사운드 옵션
- 선택 영역 액션 바: 취소, 로컬 OCR, 복사, 저장
- 인라인 주석 도구: 사각형, 타원, 직선, 화살표, 펜, 텍스트, 설명을 추가할 수 있는 번호 단계, 모자이크, 스포트라이트 하이라이트
- 주석 객체의 이동, 크기 조절, 스타일 변경, 삭제, 실행 취소 / 다시 실행 및 상황에 맞는 커서 전환
- 도구별 색상, 불투명도, 두께, 선 종류, 채우기, 화살표, 텍스트, 모자이크, 하이라이트 스타일 저장
- 도구별 스타일은 재시작 후에도 유지
- PNG를 "다운로드"에 출력
- 선택형 텍스트 및 로고 워터마크(둘 다 가능), 메뉴바에서 `{date}` `{time}` `{datetime}` 자리표시자로 설정
- 스크린샷과 클립보드 이미지를 "항상 위에" 데스크톱 창으로 핀 고정
- SHA-256 콘텐츠 중복 제거를 사용하는 영구 핀 라이브러리, 최근 100개까지 보관
- 핀의 불투명도, 모서리 둥글기, 현재 데스크톱 전용 / 모든 데스크톱 표시, 픽셀 단위 화살표 이동, 모두 숨기기 / 보이기
- 핀의 우클릭 또는 더블클릭으로 보조 주석
- macOS Vision을 사용한 온디바이스 중국어·영어 텍스트 인식, 결과 미리보기 편집 가능
- macOS 15 이상에서 Apple Translation을 사용한 온디바이스 영→간체 중국어 번역
- MP4 비디오와 적응형 GIF 영역 녹화를 단일 흐름으로 통합, 3–2–1 시작 카운트다운, 시스템 오디오 옵션, 내장/외장 마이크 선택, 커서 캡처, 일시정지/재개, 실시간 주석
- 녹화 미리보기에서 저장, 클립보드 복사, 폐기
- 화면, 시스템 오디오, 마이크 녹화 권한 요청

## 캡처 작업 흐름

1. 설정된 단축키를 누르거나 메뉴바에서 `Capture Region`을 선택합니다.
2. 드래그하여 영역을 선택합니다.
3. 선택 영역을 옮기거나 가장자리/모서리 핸들을 드래그해 크기를 조정한 다음, 주석 도구를 선택해 선택 이미지를 고정하고 편집 모드로 들어갑니다.
4. 주석을 추가하고 편집한 뒤, 원본 이미지에서 텍스트를 인식하거나 평탄화된 결과를 클립보드에 복사하거나 다운로드에 저장합니다. 새로 만든 주석은 계속 선택된 상태로 유지되므로, 현재 그리기 도구를 바꾸지 않고 바로 옮기거나 크기를 조절할 수 있습니다.

`text.viewfinder` 버튼은 Mac에서 완전히 로컬로 OCR을 실행하고 편집 가능한 결과 창을 엽니다. macOS 15 이상에서는 콤팩트한 좌우 분할 결과 창에서 Apple의 온디바이스 번역 UI로 현재 편집 중인 영어 텍스트를 간체 중국어로 번역할 수 있습니다. 메뉴바의 `Enable OCR English to Chinese` 체크 항목으로 이 기능을 켜고 끕니다. macOS 13/14에서는 메뉴에 호환성 안내가 표시됩니다. 첫 사용 시 macOS가 언어 모델을 다운로드하도록 요청할 수 있습니다. 원문 또는 번역 모두를 복사하면 일반 텍스트가 클립보드에 들어갑니다. 주석 모드에서 OCR은 항상 고정된 원본 스크린샷을 읽으므로, 화살표, 텍스트, 모자이크 등 주석은 무시됩니다.

선택 영역이 활성화된 동안 `Command + C` 또는 `Command + S`로 복사/저장을 할 수 있습니다. 글로벌 단축키는 메뉴바의 `Preferences...`에서 변경할 수 있습니다.

`Full Screen Capture`을 선택하거나 `Control + Option + F`를 누르면 마우스 아래의 디스플레이를 고정하고 그 디스플레이 전체를 미리 선택합니다. 일반 Brushot 액션과 주석 컨트롤은 그대로 사용할 수 있으므로 출력 전에도 선택 영역을 조정할 수 있습니다.

`Delayed Capture...`을 선택하거나 `Control + Option + D`를 누르면 먼저 영역을 고른 뒤 카운트다운을 시작합니다. Brushot은 카운트다운 동안 데스크톱을 다시 활성 상태로 되돌리고 시간이 만료된 순간의 현재 픽셀을 캡처합니다. 캡처 직전에는 테두리와 카운트다운 HUD가 숨겨집니다. 지연 시간의 기본값은 5초이며, 1~60초 사이에서 설정할 수 있고 카운트다운 사운드도 함께 설정할 수 있습니다.

워터마크는 메뉴바의 `Watermark Settings...`(`Preferences...` 아래)에서 설정할 수 있습니다. Brushot은 텍스트, 로고 이미지, 또는 둘을 함께 지원하며, 위치, 불투명도, 크기, 여백, 텍스트 색상을 지정할 수 있습니다. 스크린샷과 녹화의 워터마크는 서로 독립적으로 켤 수 있지만 동일한 비주얼 스타일을 공유합니다. 녹화 워터마크는 녹화 시작 시각을 `{date}` `{time}` `{datetime}`의 값으로 사용하여 비디오/GIF 픽셀에 그대로 굽습니다. OCR은 원본 이미지를 읽습니다.

주석 도구 단축키는 `V/R/O/L/A/P/T/N/M/H`입니다. 실행 취소와 다시 실행은 `Command + Z`와 `Shift + Command + Z`이며, 선택된 주석의 삭제는 `Delete`입니다. 텍스트 편집 중 확정과 취소는 각각 `Command + Return`과 `Escape`입니다.

주석 처리된 스크린샷의 빈 부분이나 텍스트가 아닌 주석을 더블클릭하면 평탄화된 PNG가 복사됩니다. 텍스트를 더블클릭하면 편집에 들어갑니다. 그리기 도구가 활성 상태일 때는 기존 주석이 포인터 이벤트를 우선 차지합니다. 겹쳐서 새 주석을 강제로 만들려면 `Option`을 누른 채 드래그하세요. 색상, 불투명도, 두께 등의 스타일은 즉시 적용되지만 실행 취소 기록에는 들어가지 않습니다.

번호 주석은 숫자 배지만 표시되며 자동으로 증가합니다. 보충 설명 텍스트를 함께 넣고 싶다면 별도의 텍스트 도구를 사용하세요.

## 녹화 작업 흐름

1. 메뉴바에서 `영역 녹화`를 선택하거나 해당 단축키(기본 `Option + R`)를 누릅니다. `전체 화면 녹화` 또는 `윈도우 녹화...`도 선택할 수 있습니다.
2. 윈도우 녹화에서는 포인터를 움직여 실시간 강조 표시를 확인한 뒤 클릭하여 해당 윈도우를 고정합니다. 이후 비디오 또는 GIF 녹화를 시작합니다. 비디오는 시스템 오디오와 선택한 마이크를 녹음할 수 있고 GIF는 항상 무음입니다.
3. 시작 전에 화면 중앙에 3–2–1 카운트다운이 나타나며 취소할 수 있습니다. 녹화 중에는 콤팩트한 플로팅 컨트롤로 일시정지, 재개, 정지, 취소, 도구바 접기/펼치기를 할 수 있습니다. 전체 화면 녹화는 컨트롤이 접힌 상태로 시작되어 화면을 덜 가립니다. 실시간 주석 바는 선택, 사각형, 화살표, 펜, 색상, 두께, 실행 취소, 다시 실행을 제공하며, 이러한 주석은 비디오와 GIF 출력 모두에 포함되지만 카운트다운, 빨간 테두리, 컨트롤 자체는 제외됩니다.
4. 내보낸 뒤 미리보기에서 결과물을 저장, 클립보드 복사 또는 폐기할 수 있습니다.

비디오는 30 FPS로 캡처되며, 네트워크 최적화된 H.264/AAC MP4로 내보내집니다. 시스템 오디오와 마이크가 모두 활성화되면 둘은 동기화되어 내보낸 오디오에 함께 믹스됩니다. GIF는 기본 너비 720px, 15 FPS로 내보내집니다. 긴 녹화에서는 자동으로 샘플링을 낮추어 결과가 대략 600 프레임을 유지하도록 합니다(이전의 30초 상한을 따르지 않습니다).

GIF 녹화는 3분 후 자동으로 멈춥니다. 비디오 녹화는 2시간 후 자동으로 멈추고 1시간이 지나면 남은 시간을 표시합니다. 여유 공간이 1GB 미만이면 녹화 시작이 차단되며, 녹화 중 여유 공간이 그 임계값 아래로 떨어지면 안전하게 중지됩니다.

## 핀 작업 흐름

- 스크린샷 도구바에서 핀 버튼을 누르면 선택 영역 또는 주석 완료된 결과가 다른 창 위에 떠 있습니다.
- 메뉴바의 `Pins` 하위 메뉴에서 `Pin from Clipboard`를 선택하면 현재 클립보드에 있는 PNG, TIFF 또는 기타 이미지 내용을 핀 고정합니다.
- 같은 하위 메뉴에서 `Pin Library...`를 선택하면 영구 핀 기록을 다시 열어 삭제하거나 비울 수 있습니다. 동일한 이미지는 한 번만 저장됩니다.
- 핀을 드래그해 이동합니다. 클릭한 뒤 화살표 키로 1픽셀, `Shift + 화살표 키`로 10픽셀 단위로 움직일 수 있습니다.
- 핀을 우클릭하면 불투명도나 모서리 둥글기를 변경하고, 현재 데스크톱에만 표시할지 또는 모든 데스크톱에 표시할지 설정할 수 있으며, 복사/저장 또는 다시 주석을 추가할 수 있습니다.
- 핀을 더블클릭하면 전체 주석 도구 세트가 열리고, 편집을 완료하면 핀이 업데이트되고 결과가 기록에 추가됩니다.
- 메뉴바의 `Hide All Pins` / `Show All Pins`으로 모든 열린 핀을 일시적으로 전환할 수 있습니다.
- 모든 글로벌 액션은 `Preferences...`에서 사용자 지정할 수 있습니다. Brushot은 macOS 또는 다른 앱이 이미 사용 중인 단축키 조합을 거절합니다.

## 소스에서 실행

```bash
swift run Brushot
```

이 경로는 개발 시 Swift Package Manager를 사용합니다. 아래 패키징 스크립트는 Xcode 툴체인을 직접 사용하고 빌드 결과물을 프로젝트 안에 보관합니다.

## `.app` 빌드

```bash
./scripts/build-app.sh
open .build/distribution/Brushot.app
```

## `.dmg` 빌드

```bash
./scripts/build-dmg.sh
open dist/Brushot.dmg
```

생성된 앱과 DMG는 모두 완전한 앱 번들로 서명됩니다. `build-app.sh`은 항상 번들 식별자 `com.brushot.app`을 사용하며, 빌드가 성공하면 `/Applications/Brushot.app`을 덮어씁니다. 이로 인해 로컬 업데이트는 같은 앱 경로를 사용하게 되어 앱을 반복해서 제거하거나 개인정보 권한을 다시 부여할 필요가 없습니다.

서명 ID 선택 순서: 명시적으로 설정된 ID → `/Applications/Brushot.app`에서 이미 사용 중인 서명 ID → Developer ID Application ID → 로그인 키체인의 첫 번째 Apple Development ID. 다른 Apple Development 또는 Developer ID를 사용하려면 다음과 같이 지정합니다:

```bash
BRUSHOT_CODESIGN_IDENTITY="Apple Development: Your Name (TEAMID)" ./scripts/build-app.sh
```

macOS 화면 녹화 권한이 첫 사용 시 필요합니다. 권한 테스트는 `swift run`이 아니라 `/Applications/Brushot.app`을 통해 실행하세요. 명령행에서 직접 빌드한 바이너리에는 패키지 앱의 서명 ID가 따라가지 않습니다.

첫 캡처에는 macOS 화면 녹화 권한이 필요합니다. 권한이 거부되면 시스템 설정 > 개인 정보 보호 및 보안 > 화면 및 시스템 오디오 녹화에서 Brushot을 활성화한 다음 앱을 재시작하세요.
