# Brushot

Brushot 是一款轻量、原生的 macOS 截图应用，主打快速截图、标注、OCR、贴图与录屏。当前版本已包含完整的截图与内联标注主链路：

通过 Universal 2 可执行文件支持 macOS 13 及以上系统，兼容 Apple Silicon 与 Intel Mac。

- 菜单栏应用
- 区域 / 全屏 / 延时 / 长截图 / 录屏 / 剪贴板贴图 / 贴图库 / 隐藏 / 显示贴图 等全局快捷键，均可在偏好设置中自定义
- 拖拽框选截图覆盖层
- 智能识别鼠标下方最前面的窗口：单击选择整个窗口，拖动则自由框选区域
- 单显示器全屏截图，自动定位鼠标所在显示器
- 1–60 秒延时区域截图，可选倒计时提示音
- 选区操作栏：取消、本地 OCR、复制、保存
- 内联标注工具：矩形、椭圆、直线、箭头、画笔、文字、带描述的序号步骤、马赛克、聚光高亮
- 标注对象可编辑：移动、缩放、改样式、删除、撤销、重做，并随上下文显示对应光标
- 每个工具的颜色、不透明度、描边宽度、线型、填充、箭头样式、文字样式、马赛克、高亮样式均独立保存
- 工具样式跨启动持久化
- PNG 输出到「下载」
- 截图与录屏的可选文字水印 / Logo 水印，可从菜单栏配置，占位符支持 `{date}`、`{time}`、`{datetime}`
- 截图与剪贴板图片以「始终置顶」窗口形式贴到桌面
- 贴图库持久化，使用 SHA-256 内容去重，最多保留 100 张最近图片
- 贴图：不透明度、圆角、仅当前桌面 / 跨桌面、像素级方向键移动、全部隐藏 / 显示
- 贴图右键或双击可发起二次标注
- 基于 macOS Vision 的设备端中英文 OCR 识别，结果预览可编辑
- 在 macOS 15 及以上支持基于 Apple Translation 的设备端英译简中
- 统一的 MP4 视频与自适应 GIF 录屏，含 3–2–1 倒计时、系统声、麦克风、摄像头画中画、暂停 / 继续与实时标注
- 录屏预览支持保存、复制到剪贴板、丢弃
- 屏幕、麦克风、系统声的录屏权限弹窗

## 截图工作流

1. 按下已配置的快捷键，或从菜单栏选择「Capture Region」。
2. 拖拽框选一个区域。
3. 移动选区，或拖动任意边缘 / 角点句柄调整大小；然后选择一个标注工具来冻结所选图像并进入编辑模式。
4. 添加与编辑标注后，可对原图识别文字、把扁平化结果复制到剪贴板，或保存到「下载」。新创建的标注保持选中状态，无需切换当前绘图工具即可继续移动或缩放。

`text.viewfinder` 按钮调用完全在本机运行的 OCR，并打开一个可编辑的结果窗口。在 macOS 15 及以上，紧凑的左右分栏结果窗口可以使用 Apple 端上 Translation 框架将当前编辑中的英文文本翻译为简体中文，可通过菜单栏的「Enable OCR English to Chinese」开关启用或关闭此功能。在 macOS 13 / 14 上菜单会展示对应的兼容性说明。macOS 可能在首次使用时下载语言模型。无论复制原文还是译文，都是纯文本写入剪贴板。在标注模式下，OCR 始终读取「冻结的」原始截图，因此箭头、文字、马赛克等标注都会被忽略。

在选区处于激活状态时，按 `Command + C` 或 `Command + S` 可执行复制与保存。打开菜单栏的「Preferences...」即可变更全局快捷键。

选择「Full Screen Capture」或按 `Control + Option + F` 可冻结鼠标下方显示器并预选其整个区域。Brushot 正常的操作与标注控件依然可用，截图前仍可调整选区。

选择「Delayed Capture...」或按 `Control + Option + D` 可先框选区域、再开始倒计时。倒计时期间 Brushot 恢复桌面像素，到点才截下当前像素；截屏前的边框与倒计时 HUD 在截屏动作发生前会被自动隐藏。延时默认值 5 秒，可在偏好设置里设为 1 到 60 秒，并配合「倒计时提示音」开关。

水印可从菜单栏的「Watermark Settings...」（位于「Preferences...」下方）配置。Brushot 支持文字、Logo 图片或两者组合，可配置位置、不透明度、大小、外边距、文字颜色。截图与录屏水印可独立启用，但共用同一视觉样式。录屏水印以录制开始时间作为 `{date}`、`{time}`、`{datetime}` 的取值，烧录进视频 / GIF 像素。OCR 读取的是原始图像。

标注工具快捷键：`V/R/O/L/A/P/T/N/M/H`。撤销 / 重做分别为 `Command + Z` 与 `Shift + Command + Z`，`Delete` 可删除当前选中标注。编辑文字时，`Command + Return` 提交，`Escape` 取消。

在已标注截图的空白区域或任意非文字标注上双击，可复制扁平化后的 PNG；双击文字直接进入编辑。在某个绘图工具激活时，现有标注会优先接受指针事件；按住 `Option` 同时拖动可强制创建一块与之重叠的新标注。颜色、不透明度、宽度等样式会立刻生效，但不进入撤销历史。

序号标注只显示数字徽章，自动递增。如需配套解释文字，请使用独立的文字工具。

## 录屏工作流

1. 从菜单栏选择「区域录屏」或按其可配置快捷键（默认 `Option + R`）；也可以选择「全屏录屏」或「窗口录屏…」。
   区域录屏的确认栏会显示「选区 宽 × 高」；点击后可输入屏幕实际像素宽高，选择自由 / 16:9 / 4:3 / 1:1 / 9:16，锁定当前比例，或恢复上次录制区域。设置收在弹出面板内，不会再遮挡其他录屏选项；全屏和窗口录屏不显示该入口。
2. 窗口录屏时，移动指针查看实时高亮，单击即可锁定这一扇窗口。开始视频录制前可分别设置分辨率（原始、4K、1080p 或 720p）和帧率（15、30 或 60 帧/秒）；选择会被记住。视频可录系统声、所选内置 / USB / 蓝牙麦克风或两者；GIF 始终静音并独立自动优化。
3. 倒计时（3–2–1）出现在屏幕中央，可以取消。录制过程中，使用紧凑的悬浮控件可以暂停、继续、停止、取消、收起 / 展开标注工具栏。全屏录制时控件默认收起，以减少遮挡。实时标注栏提供选择、矩形、箭头、画笔、颜色、描边宽度、撤销、重做；标注会同时进入视频与 GIF 输出，倒计时、红色边框、控件本身不会进入画面。
4. 导出后，预览结果可保存到指定位置、复制到剪贴板或丢弃。

视频默认使用 1080p、30 帧/秒，可改为原始 / 4K / 720p 与 15 / 60 帧/秒；缩放保持宽高比、不裁剪，也不会放大小于目标档位的画面。视频导出为网络优化 H.264/AAC MP4。系统声与麦克风同时启用时，两者会被同步并混合到导出音频中。GIF 导出默认 720 像素宽、15 帧/秒；长录制会自动降采样，让结果帧数大致保持在 600 帧上下，而非过去的 30 秒硬上限。

每次开始新的录制时，摄像头画中画默认关闭。左右翻转首次使用时默认开启；开启摄像头后，可从「画中画设置」选择圆形 / 圆角矩形、小 / 中 / 大、四角位置和左右翻转，设备、位置、尺寸、形状与左右翻转都会记住上一次的选择。画中画也可在选区内直接拖动、缩放和靠边吸附，录制中仍能开关并实时修改这些设置。首次请求摄像头权限时会等待授权完成再允许开始录制。摄像头断开或启动失败不会中断屏幕录制。摄像头画面会进入视频成片，但 GIF 不使用摄像头。

GIF 录制 3 分钟后自动停止；视频录制 2 小时后自动停止，并在第 1 小时后显示剩余时间。磁盘可用空间低于 16 GB 时会警告，低于 12 GB 时禁止开始，录制中低于 12 GB 时安全停止，避免 macOS 因磁盘压力强制中断录屏。

## 贴图工作流

- 点击截图工具栏中的贴图按钮，把选区或标注完成的结果浮在所有窗口之上。
- 打开菜单栏的「Pins」子菜单，选择「Pin from Clipboard」可贴上当前剪贴板里的 PNG、TIFF 或其它图像内容。
- 在同一子菜单选择「Pin Library...」可重新打开、删除或清空持久化的贴图历史。相同内容的图片只会保存一份。
- 拖动贴图以移动它。单击后，使用方向键可逐像素移动，按住 `Shift + 方向键` 每次移动 10 像素。
- 在贴图上点右键可调整不透明度或圆角，设置"仅当前桌面 / 跨桌面"、复制 / 保存、再次标注。
- 双击贴图打开完整标注工具集；完成编辑后贴图会更新，并把编辑结果加入历史。
- 通过菜单栏的「Hide All Pins」/「Show All Pins」临时切换所有已打开的贴图。
- 在「Preferences...」里自定义所有全局动作。Brushot 会拒绝已被 macOS 或其它应用占用的快捷键组合。

## 从源码运行

```bash
swift run Brushot
```

该路径使用 Swift Package Manager 开发。下面介绍的打包脚本直接使用 Xcode 工具链，并把构建产物保留在项目内。

## 构建 `.app`

```bash
./scripts/build-app.sh
open .build/distribution/Brushot.app
```

## 构建 `.dmg`

```bash
./scripts/build-dmg.sh
open dist/Brushot.dmg
```

打包后的 app 与 DMG 都作为完整的 app bundle 进行了签名。`build-app.sh` 始终使用 bundle identifier `com.brushot.app`，并会在构建成功之后覆盖 `/Applications/Brushot.app`，这样本地更新会使用同一应用路径，无需重复移除 app 或重新授予隐私权限。

构建按以下顺序选择签名身份：先使用显式配置的身份，再使用 `/Applications/Brushot.app` 已使用的签名身份，再使用 Developer ID Application 身份，最后使用登录钥匙串里第一个 Apple Development 身份。如需选择不同的 Apple Development 或 Developer ID 身份：

```bash
BRUSHOT_CODESIGN_IDENTITY="Apple Development: Your Name (TEAMID)" ./scripts/build-app.sh
```

首次使用需要 macOS 屏幕录制权限。进行权限测试时，请启动 `/Applications/Brushot.app` 而不是 `swift run`，因为命令行直接构建的产物没有打包 app 的签名身份。

首次截图需要 macOS 屏幕录制权限。如被拒绝，请在「系统设置 > 隐私与安全性 > 屏幕与系统音频录制」中勾选 Brushot，然后重启应用。
