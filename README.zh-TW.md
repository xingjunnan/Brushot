# Brushot

Brushot 是一款輕量、原生的 macOS 截圖應用程式，主打快速截圖、標註、OCR、釘選與錄製螢幕。目前版本已包含完整的截圖與內嵌標註主迴圈：

透過 Universal 2 可執行檔支援 macOS 13 及以上系統，相容 Apple Silicon 與 Intel Mac。

- 選單列應用程式
- 區域 / 全螢幕 / 延遲 / 長截圖 / 錄製 / 剪貼簿釘選 / 釘選資料庫 / 隱藏 / 顯示釘選 等全域快捷鍵，均可在偏好設定中自訂
- 拖曳框選截圖覆蓋層
- 智慧辨識滑鼠下方最前面的視窗：按一下選取整個視窗，拖曳則自由框選區域
- 單螢幕全螢幕截圖，自動定位滑鼠所在螢幕
- 1–60 秒延遲區域截圖，可選倒數提示音
- 選區動作列：取消、本機 OCR、複製、儲存
- 內嵌標註工具：矩形、橢圓、直線、箭頭、畫筆、文字、含描述的編號步驟、馬賽克、聚光高亮
- 標註物件可編輯：移動、縮放、改樣式、刪除、復原、重做，並隨內容切換對應游標
- 每個工具的顏色、不透明度、描邊寬度、線型、填色、箭頭樣式、文字樣式、馬賽克、高亮樣式均獨立保存
- 工具樣式跨啟動持續保存
- PNG 輸出到「下載項目」
- 截圖與錄製的選用文字浮水印 / Logo 浮水印，可從選單列設定，佔位符支援 `{date}`、`{time}`、`{datetime}`
- 截圖與剪貼簿圖片以「永遠置頂」視窗形式釘到桌面
- 釘選資料庫持續保存，採用 SHA-256 內容去重，最多保存 100 張最新圖片
- 釘選：不透明度、圓角、僅當前桌面 / 跨桌面、像素級方向鍵移動、全部隱藏 / 顯示
- 釘選右鍵或雙擊可進行二次標註
- 基於 macOS Vision 的裝置端繁體 / 簡體中文與英文 OCR 識別，結果預覽可編輯
- 在 macOS 15 及以上支援基於 Apple Translation 的裝置端英譯簡中
- 統一的 MP4 影片與自適應 GIF 錄製，含 3–2–1 倒數、系統聲、麥克風、攝影機子母畫面、暫停 / 繼續與即時標註
- 錄製預覽支援儲存、複製到剪貼簿、丟棄
- 螢幕、麥克風、系統聲的錄製權限彈窗

## 截圖工作流程

1. 按下已設定的快捷鍵，或從選單列選擇「Capture Region」。
2. 拖曳框選一個區域。
3. 移動選區，或拖曳任一邊緣 / 角落把手調整大小；接著選一個標註工具以凍結所選影像並進入編輯模式。
4. 新增與編輯標註後，可對原圖識別文字、把壓平後的結果複製到剪貼簿，或儲存到「下載項目」。新建立的標註會保持選中狀態，無需切換目前繪圖工具即可繼續移動或縮放。

`text.viewfinder` 按鈕會呼叫完全在本機執行的 OCR，並開啟一個可編輯的結果視窗。在 macOS 15 及以上時，緊湊的左右分欄結果視窗可使用 Apple 端上 Translation 框架把目前編輯中的英文文字翻譯為簡體中文，可透過選單列的「Enable OCR English to Chinese」開關啟用或關閉此功能。在 macOS 13 / 14 上選單會顯示對應的相容性說明。macOS 可能會在首次使用時下載語言模型。不論複製原文或譯文，都是純文字寫入剪貼簿。在標註模式下，OCR 永遠讀取「凍結的」原始截圖，因此箭頭、文字、馬賽克等標註都會被忽略。

在選區處於啟用狀態時，按 `Command + C` 或 `Command + S` 可執行複製與儲存。開啟選單列的「Preferences...」即可變更全域快捷鍵。

選擇「Full Screen Capture」或按 `Control + Option + F` 可凍結滑鼠下方螢幕並預選其整個區域。Brushot 正常的動作與標註控制項依然可用，輸出前仍可調整選區。

選擇「Delayed Capture...」或按 `Control + Option + D` 可先框選區域、再開始倒數。倒數期間 Brushot 還原桌面像素，到點才截下當下像素；截圖前的邊框與倒數 HUD 在截圖動作發生前會自動隱藏。延遲預設 5 秒，可在偏好設定裡設為 1 到 60 秒，並搭配「倒數提示音」開關。

浮水印可從選單列的「Watermark Settings...」（位於「Preferences...」下方）設定。Brushot 支援文字、Logo 圖片或兩者組合，可設定位置、不透明度、大小、外邊距、文字顏色。截圖與錄製浮水印可各自獨立啟用，但共用同一視覺樣式。錄製浮水印以錄製開始時間作為 `{date}`、`{time}`、`{datetime}` 的取值，燒錄到影片 / GIF 像素。OCR 讀取的是原始影像。

標註工具快捷鍵：`V/R/O/L/A/P/T/N/M/H`。復原 / 重做分別為 `Command + Z` 與 `Shift + Command + Z`，`Delete` 可刪除目前選中的標註。編輯文字時，`Command + Return` 確認，`Escape` 取消。

在已標註截圖的空白處或任一非文字標註上雙擊，可複製壓平後的 PNG；雙擊文字直接進入編輯。當某個繪圖工具啟用時，現有標註會優先接收指標事件；按住 `Option` 同時拖曳可強制建立一塊與之重疊的新標註。顏色、不透明度、寬度等樣式會立刻生效，但不進入復原歷史。

編號標註只顯示數字徽章，自動遞增。如需附帶說明文字，請使用獨立的文字工具。

## 錄製工作流程

1. 從選單列選擇「區域錄製」或按下其可設定的快捷鍵（預設 `Option + R`）；也可選擇「全螢幕錄製」或「視窗錄製…」。
   區域錄製的確認列會顯示「選區 寬 × 高」；點擊後可輸入螢幕實際像素寬高，選擇自由 / 16:9 / 4:3 / 1:1 / 9:16、鎖定目前比例，或還原上次錄製區域。設定收在彈出面板內，不會遮擋其他錄製選項；全螢幕與視窗錄製不顯示該入口。
2. 視窗錄製時，移動指標查看即時醒目顯示，按一下即可鎖定該視窗。接著選擇開始錄製影片或 GIF；影片可錄系統聲與所選麥克風，GIF 永遠靜音。
3. 倒數（3–2–1）出現在螢幕中央，可以取消。錄製過程中，緊湊的浮動控制列可拖到螢幕內任意位置，並可暫停、繼續、停止、取消、收合 / 展開標註工具列。全螢幕錄製時控制項預設收合，以減少遮擋。即時標註列提供選擇、矩形、箭頭、畫筆、顏色、描邊寬度、復原、重做；標註會同時進入影片與 GIF 輸出，倒數、紅色邊框、控制項本身不會進入畫面。
4. 匯出後，預覽結果可儲存到指定位置、複製到剪貼簿或丟棄。

影片預設使用 1080p、30 幀/秒，可改為原始 / 4K / 720p 與 15 / 60 幀/秒；縮放會保持長寬比、不裁切，也不會放大小於目標規格的畫面，並記住選擇。影片匯出為網路最佳化 H.264/AAC MP4。系統聲與麥克風同時啟用時，兩者會被同步並混合到匯出音訊中。GIF 匯出預設寬度 720 像素、15 幀/秒；長錄製會自動降採樣，讓結果幀數大約保持在 600 幀上下，而非過去的 30 秒硬上限。

每次開始新錄製時，攝影機子母畫面預設關閉。左右翻轉首次使用時預設開啟；開啟攝影機後，可從「子母畫面設定」選擇圓形 / 圓角矩形、小 / 中 / 大、四角位置和左右翻轉，裝置、位置、尺寸、形狀與左右翻轉都會記住上一次的選擇。錄製中仍可開關並即時修改設定。首次要求攝影機權限時，會等待授權完成後才允許開始錄製。攝影機斷線或啟動失敗不會中斷螢幕錄製。攝影機會進入影片成品，但 GIF 不使用攝影機。

GIF 錄製 3 分鐘後自動停止；影片錄製 2 小時後自動停止，並在第 1 小時後顯示剩餘時間。磁碟可用空間低於 16 GB 時會警告，低於 12 GB 時禁止開始，錄製中低於 12 GB 時安全停止，避免 macOS 因磁碟壓力強制中斷錄製。

## 釘選工作流程

- 點擊截圖工具列中的釘選按鈕，把選區或標註完成的結果浮在所有視窗之上。
- 開啟選單列的「Pins」子選單，選擇「Pin from Clipboard」可釘上目前剪貼簿裡的 PNG、TIFF 或其他影像內容。
- 在同一子選單選擇「Pin Library...」可重新開啟、刪除或清空持續保存的釘選歷史。相同內容的圖片只會保存一份。
- 拖曳釘選影像以移動它。點選後，使用方向鍵可逐像素移動，按住 `Shift + 方向鍵` 每次移動 10 像素。
- 在釘選影像上按右鍵可調整不透明度或圓角，設定「僅當前桌面」/「跨桌面」、複製 / 儲存、再次標註。
- 雙擊釘選影像開啟完整標註工具集；完成編輯後釘選會更新，並把編輯結果加入歷史。
- 透過選單列的「Hide All Pins」/「Show All Pins」可暫時切換所有已開啟的釘選。
- 在「Preferences...」可自訂所有全域動作。Brushot 會拒絕已被 macOS 或其他應用佔用的快捷鍵組合。

## 從原始碼執行

```bash
swift run Brushot
```

此路徑使用 Swift Package Manager 開發。下列打包腳本直接使用 Xcode 工具鏈，並把建置產物保留在專案內。

## 建置 `.app`

```bash
./scripts/build-app.sh
open .build/distribution/Brushot.app
```

## 建置 `.dmg`

```bash
./scripts/build-dmg.sh
open dist/Brushot.dmg
```

打包後的 app 與 DMG 都作為完整的 app 套件進行簽署。`build-app.sh` 始終使用套件識別碼 `com.brushot.app`，並在建置成功之後覆蓋 `/Applications/Brushot.app`，這樣本機更新會使用同一應用路徑，無需重複移除 app 或重新授予隱私權限。

簽署身份依以下順序選擇：先使用明確設定的身份，再使用 `/Applications/Brushot.app` 已使用的簽署身份，再使用 Developer ID Application 身份，最後使用登入鑰匙圈裡第一個 Apple Development 身份。如需選擇不同的 Apple Development 或 Developer ID 身份：

```bash
BRUSHOT_CODESIGN_IDENTITY="Apple Development: Your Name (TEAMID)" ./scripts/build-app.sh
```

首次使用需要 macOS 螢幕錄製權限。進行權限測試時，請啟動 `/Applications/Brushot.app` 而不是 `swift run`，因為命令列直接建置的產物沒有打包 app 的簽署身份。

首次截圖需要 macOS 螢幕錄製權限。如被拒，請在「系統設定 > 隱私與安全性 > 螢幕與系統音訊錄製」中勾選 Brushot，然後重新啟動應用程式。
