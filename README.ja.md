# Brushot

Brushot は、軽量でネイティブな macOS 用のスクリーンショットアプリで、高速キャプチャ、アノテーション、OCR、ピンニング、画面録画を提供します。現在のビルドには、キャプチャとインラインアノテーションの完全なループが含まれています：

macOS 13 以降（Apple Silicon と Intel Mac の両方）を、Universal 2 バイナリでサポートします。

- メニューバー常駐型のアプリ
- 領域 / フルスクリーン / 遅延 / スクロールキャプチャ、録画、クリップボードからのピン留め、ピン留めライブラリの表示・非表示、などを設定可能なグローバルショートカットで操作
- ドラッグして範囲選択するキャプチャオーバーレイ
- ポインタ下の最前面ウィンドウを自動検出：クリックでウィンドウ全体を選択し、ドラッグで任意の範囲を選択
- シングルディスプレイのフルスクリーンキャプチャと、その時マウスがあるディスプレイの自動検出
- 1〜60 秒の遅延キャプチャ（任意の秒数とカウントダウン音の ON/OFF）
- 選択範囲のアクションバー：キャンセル、ローカル OCR、コピー、保存
- インラインアノテーション：矩形、楕円、直線、矢印、ペン、テキスト、番号付きステップ（任意の補足テキスト付き）、モザイク、スポットライトハイライト
- アノテーションオブジェクトの編集：移動、リサイズ、スタイル変更、削除、元に戻す・やり直し、状況に応じてカーソルが切替
- ツールごとに色・不透明度・太さ・線種・塗りつぶし・矢印スタイル・テキストスタイル・モザイク・ハイライトを保持
- ツール別スタイルはアプリを再起動しても保持
- PNG を「ダウンロード」に出力
- テキストおよび Logo ウォーターマーク（任意の合成可）を `{date}` `{time}` `{datetime}` プレースホルダー付きでメニューから設定
- スクリーンショットとクリップボード画像を「常に最前面」のデスクトップウィンドウとしてピン留め
- ピン留めライブラリを永続化、SHA-256 による重複排除、最新 100 件まで保存
- ピン：不透明度、角丸、現在のデスクトップのみ / 全デスクトップ、ピクセル単位の矢印キー移動、全ピン表示 / 非表示
- 右クリックまたはダブルクリックで、ピン留め画像に二次的なアノテーションを追加
- macOS Vision によるオンデバイス中文・英語 OCR（結果プレビューは編集可）
- macOS 15 以降では Apple Translation によるオンデバイス英→簡体中国語翻訳
- MP4 動画と適応型 GIF の録画を統合、3–2–1 カウントダウン、システム音、マイク、カメラのピクチャ・イン・ピクチャ、一時停止・再開、ライブアノテーション
- 録画プレビューで保存・クリップボードコピー・破棄
- 画面・システム音・マイクの録音権限を初回起動時にリクエスト

## キャプチャ手順

1. 設定済みのショートカットを押すか、メニューバーから `Capture Region` を選択します。
2. ドラッグして範囲を指定します。
3. 選択範囲を移動したり、エッジ / コーナーのハンドルをドラッグしてリサイズできます。次に、いずれかのアノテーションツールを選ぶと、選択画像が凍結され編集モードに入ります。
4. アノテーションを追加・編集した後、元の画像のテキストを認識したり、フラット化した結果をクリップボードへコピーしたり、ダウンロードに保存したりできます。新しく作成したアノテーションは選択状態のまま保持され、現在の描画ツールを切り替えずに移動・リサイズできます。

`text.viewfinder` ボタンはローカルで完結する OCR を実行し、編集可能な結果ウィンドウを開きます。macOS 15 以降では、コンパクトな並べ替え可能な結果ウィンドウに Apple のオンデバイス翻訳 UI を組み込み、編集中の英文を簡体中国語へ翻訳できます。メニュー `Enable OCR English to Chinese` でこの機能を切り替えられます。macOS 13 / 14 では、メニューに互換性に関する注記が表示されます。初回利用時に macOS が言語モデルのダウンロードを促すことがあります。原文と翻訳、いずれのコピーもプレーンテキストをクリップボードに書き込みます。アノテーションモードでは OCR は常に凍結された元のスクリーンショットを読むため、矢印・テキスト・モザイク等のアノテーションは無視されます。

選択範囲がアクティブな状態で `Command + C` または `Command + S` を押すと、コピーまたは保存を実行できます。グローバルショートカットは、メニューバーの `Preferences...` から変更できます。

`Full Screen Capture` を選択するか `Control + Option + F` を押すと、マウスがあるディスプレイをフリーズし、そのディスプレイの全範囲をプリセレクトします。通常の Brushot の操作とアノテーションのコントロールはそのまま使えるので、出力前にも選択範囲を調整できます。

`Delayed Capture...` を選択するか `Control + Option + D` を押すと、先に範囲を選んだあとにカウントダウンを開始します。Brushot はカウントダウン中はデスクトップをライブ状態に戻し、時間が来た瞬間のピクセルをキャプチャします。キャプチャ直前に、ボーダーとカウントダウン HUD は非表示にされます。遅延時間のデフォルトは 5 秒で、Preferences から 1〜60 秒に変更でき、カウントダウン音も設定可能です。

ウォーターマークは、メニューバーの `Watermark Settings...`（`Preferences...` の下）から設定できます。Brushot はテキスト、Logo 画像、または両方の組み合わせ、配置、不透明度、サイズ、余白、文字色をサポートしています。スクリーンショットと録画のウォーターマークはそれぞれ独立に有効化できますが、同じビジュアルスタイルを共有します。録画ウォーターマークは録画開始時刻を `{date}` `{time}` `{datetime}` の値として用いて、動画 / GIF のピクセルに直接焼き込まれます。OCR は元の画像を読みます。

アノテーションツールのショートカットは `V/R/O/L/A/P/T/N/M/H` です。元に戻す・やり直しは `Command + Z` と `Shift + Command + Z`、選択中のアノテーションの削除は `Delete` です。テキスト編集中の確定は `Command + Return`、キャンセルは `Escape` です。

注釈済みのスクリーンショットの空白部分、またはテキスト以外のアノテーションをダブルクリックすると、フラット化された PNG をコピーできます。テキストをダブルクリックすると編集に入ります。描画ツールがアクティブな間は、既存のアノテーションがポインタの優先対象になります。重なった新しいアノテーションを強制的に作るには、`Option` を押しながらドラッグします。色・不透明度・太さなどのスタイルは即時に適用されますが、Undo 履歴には入りません。

シーケンス（数字）アノテーションは数字バッジのみで、自動でインクリメントします。補足説明を加えたい場合は、独立したテキストツールを使ってください。

## 録画手順

1. メニューバーの「範囲を収録」を選ぶか、設定可能なショートカット（デフォルト `Option + R`）を押します。「画面全体を収録」または「ウインドウを収録...」も選べます。
   範囲収録の確認バーには「選択範囲 幅 × 高さ」が表示されます。クリックすると実ピクセルの正確な値、自由 / 16:9 / 4:3 / 1:1 / 9:16、縦横比の固定、前回収録した範囲の復元を設定できます。設定はポップオーバーに収まり、ほかの録画設定を覆いません。画面全体とウインドウ収録では表示されません。
2. ウインドウ収録ではポインタを動かしてライブハイライトを確認し、クリックしてそのウインドウを固定します。その後、動画または GIF の開始を選びます。動画はシステム音と選択したマイクを収録でき、GIF は常に無音です。
3. 録画開始前に 3–2–1 のカウントダウンが画面中央に表示され、中止できます。録画中はコンパクトなフローティングコントロールで一時停止・再開・停止・キャンセル・ツールバーの折りたたみ / 展開を行えます。フルスクリーン録画ではコントロールが折りたたまれた状態で開始され、画面をあまり覆いません。リアルタイムアノテーションバーでは選択・矩形・矢印・ペン・色・太さ・Undo・Redo を提供し、これらのアノテーションは動画と GIF の両方の出力に含まれますが、カウントダウン・赤い枠・コントロール自体は含まれません。
4. エクスポート後、プレビューから保存・クリップボードコピー・破棄を選べます。

動画は既定で 1080p / 30 FPS を使用し、オリジナル、4K、720p と 15 / 60 FPS も選択できます。縦横比を維持して切り抜きや小さい映像の拡大は行わず、選択内容を記憶します。動画はネットワークに優しい H.264/AAC MP4 としてエクスポートされます。システム音とマイクの両方を有効化した場合、二つは同期され、ミックスされた状態でエクスポート音声に含まれます。GIF は既定で幅 720 ピクセル、15 FPS でエクスポートされます。長時間の録画では自動的にサンプリングを下げ、おおむね 600 フレーム前後を維持します（従来の 30 秒上限に依存しません）。

カメラのピクチャ・イン・ピクチャは新しい録画ごとにオフで始まります。左右反転は初回のみオンが既定値です。カメラを有効にすると、設定から円形 / 角丸長方形、小 / 中 / 大、四隅、左右反転を選択でき、デバイス・位置・サイズ・形状・左右反転の前回の選択が記憶されます。録画中もオン / オフと設定変更をリアルタイムで行えます。初回はカメラ権限の結果が出るまで録画開始を無効にします。カメラの切断や起動失敗が画面録画を止めることはありません。GIF ではカメラを使用しません。

GIF 録画は 3 分で自動停止します。動画録画は 2 時間で自動停止し、1 時間を超えると残り時間が表示されます。空き容量が 16 GB 未満の場合は警告し、12 GB 未満では開始をブロックします。録画中に 12 GB 未満になると、macOS が強制終了する前に安全に停止します。

## ピン留め手順

- スクリーンショットツールバーのピン留めボタンをクリックすると、選択中または注釈済みの結果がほかのウィンドウより上に表示されます。
- メニューバーの `Pins` サブメニューから `Pin from Clipboard` を選ぶと、現在クリップボードにある PNG、TIFF、その他の画像コンテンツをピン留めできます。
- 同じサブメニューで `Pin Library...` を選ぶと、永続化されたピン履歴を再び開いて、削除やクリアを行えます。内容が同じ画像は 1 度しか保存されません。
- ピン留め画像はドラッグで移動できます。クリック後、矢印キーで 1 ピクセル単位、`Shift + 矢印キー` で 10 ピクセル単位の移動ができます。
- ピン留め画像を右クリックすると、不透明度や角丸の変更、「現在のデスクトップのみ」 / 「全デスクトップ」の設定、コピー / 保存、再アノテーションを行えます。
- ダブルクリックで完全なアノテーションツールが開き、編集を確定するとピンが更新され、その結果が履歴に追加されます。
- メニューバーの `Hide All Pins` / `Show All Pins` ですべてのピンを一時的に切り替えられます。
- すべてのグローバルアクションは `Preferences...` でカスタマイズできます。Brushot は macOS や他のアプリと衝突するショートカットを拒否します。

## ソースから実行

```bash
swift run Brushot
```

このパスは開発用に Swift Package Manager を使用します。下記のパッケージングスクリプトは Xcode ツールチェーンを直接利用し、ビルド成果物をプロジェクト内に保持します。

## `.app` をビルド

```bash
./scripts/build-app.sh
open .build/distribution/Brushot.app
```

## `.dmg` をビルド

```bash
./scripts/build-dmg.sh
open dist/Brushot.dmg
```

生成された app と DMG はアプリとして完全に署名されています。`build-app.sh` は常に bundle identifier `com.brushot.app` を使い、ビルド成功時に `/Applications/Brushot.app` を上書きします。これによりローカルでのアップデートでは同じアプリパスが使われ、アプリの再削除やプライバシー権限の再付与は不要です。

署名の選択順序は次のとおりです: 明示的に設定された ID → `/Applications/Brushot.app` が既に使っている署名 ID → Developer ID Application ID → ログインキーチェーンにある最初の Apple Development ID。別の Apple Development / Developer ID を選びたい場合は、次のように指定します:

```bash
BRUSHOT_CODESIGN_IDENTITY="Apple Development: Your Name (TEAMID)" ./scripts/build-app.sh
```

macOS の画面収録許可が初回に必要です。権限テストをするときは `swift run` ではなく `/Applications/Brushot.app` を起動してください。コマンドラインから直接ビルドしたバイナリにはパッケージ版と同じ署名 ID が付きません。

最初のキャプチャに macOS の画面収録許可が必要です。拒否された場合は、システム設定 > プライバシーとセキュリティ > 画面とシステムオーディオの収録 で Brushot を有効化し、アプリを再起動してください。
